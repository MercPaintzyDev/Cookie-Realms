FAQ

Questions, answered.

Does this website store cookies?

No. The page does not create document cookies, localStorage entries, or sessionStorage entries. Your browser may still keep normal history, cache, DNS data, or other browser-level records.

Does the download require an account?

No account is required by this static page. The download button points directly to the ZIP file located at files/CookieRealms.zip.

Where should I put the ZIP file?

Create a folder named files beside this index.html and place your actual CookieRealms.zip inside it.

Is the website tracking visitors?

This version contains no analytics provider, tracking pixel, third-party script, or intentional visitor-storage mechanism.
